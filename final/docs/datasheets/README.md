## HC-SR04 ultrasonic sensor

| Spec | Value | Where it matters in this design |
|---|---|---|
| Supply | 5 V DC, about 15 mA | Runs straight off the Uno's 5 V rail |
| Range | 2 cm to 4 m | The code's 12 ms echo timeout cuts this to about 2 m |
| Beam angle | about 15° | Why objects show up as arcs, and why steps bigger than 1° lose little |
| Trigger | 10 µs high pulse on Trig | `digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10);` |
| Echo | High for as long as the sound's round trip | Measured with `pulseIn()` |
| Distance | time × speed of sound ÷ 2 (or µs ÷ 58 = cm) | `duration * 0.0343 / 2` in `readDistance()` |
| Measurement cycle | **at least 60 ms between pings** | The sketch pings about every 30 ms — see problems-and-fixes #4 |

## SG90 micro servo

| Spec | Value | Where it matters in this design |
|---|---|---|
| Supply | 4.8 V (about 5 V) | Runs off the 5 V rail; current spikes are why C1 (100 µF) is there |
| Speed | about 0.1 s per 60° | A 1° step takes under 2 ms, so the 30 ms `STEP_DELAY` is plenty |
| Stall torque | 1.8 kg·cm | Easily turns the HC-SR04 (under 10 g) |
| Dead band | 10 µs | Tiny pulse changes are ignored, so very small moves can stall |
| Control signal | pulse every 20 ms; about 1 ms to 2 ms wide sets the angle | Generated by the Arduino `Servo` library |
| Weight | 9 g | — |
| Temperature | 0 to 55 °C | — |
| Wires | brown = GND, red = +5 V, orange = signal | Wiring table in [hardware/README.md](../../hardware/README.md) |

## LCD1602 display (LCD-1602A)

| Spec | Value | Where it matters in this design |
|---|---|---|
| Logic supply (VDD) | 4.5–5.5 V, absolute max 7 V | Uno's 5 V is safe; never the raw 9 V battery |
| Logic current | about 1.2 mA | — |
| Input voltage | between VSS and VDD | Uno's 0–5 V logic is fine |
| Contrast | VDD − V0 = 3.8 V at 25 °C, so V0 ≈ 1.2 V | Set with the 10 kΩ pot; **measured 1.278 V** |
| R/W pin | high = read, low = write | Tied to GND: the radar only writes |
| Backlight (pins 15/16) | rated for +5.0 V | 220 Ω added in series as extra protection |
| Controller | HD44780-compatible, 4-bit or 8-bit bus | Used in 4-bit mode, so D0–D3 are not connected |

## Active buzzer

The kit's buzzer has no part number printed on it. The TMB12A05 is the standard 12 mm, 5 V
active buzzer of this type, so its datasheet is used as the reference.

| Spec | Value | Where it matters in this design |
|---|---|---|
| Rated voltage | 5 V DC (works 3–7 V) | Driven straight from Uno pin D6 |
| Current | 30 mA max | Within an Uno pin's 40 mA absolute max, so no transistor needed |
| Sound | at least 95 dB at 10 cm, about 2.4 kHz | "Active" = built-in oscillator, so the code only switches it on and off |
